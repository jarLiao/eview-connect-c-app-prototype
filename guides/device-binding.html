蓝牙接入、设备绑定与解绑技术说明

蓝牙接入先连接读取完整 IMEI 和固件身份，再进入产品与使用者确认；云端绑定双视图回查一致后保存本地 BLE 关联。

绑定目标是本人名下 ACTIVE 的人员或宠物。解绑解除一条关联，不等于删除设备或转移所有权。

1用哪些接口

  1. 选择使用者GET/app/subjects筛出本人 ACTIVE 人员 / 宠物
  2. 核对使用者详情GET/app/subjects/person/{personId}GET/app/subjects/pet/{petId}写入及回查前确认身份、归属、状态
  3. 读取可选产品GET/app/device/products按 productKey 选择，不能硬编码型号
  4. 读取已有设备的产品GET/app/device/{deviceId}/product管理页先确认自有关系；不用于探测未绑定设备
  5. 读取对象侧设备关联GET/app/subjects/person/{personId}/device-bindingsGET/app/subjects/pet/{petId}/device-bindings与通用查询对照
  6. 读取通用绑定视图GET/app/device/bindingsquery：bindType、bindToId
  7. 绑定设备POST/app/device/bind一次 POST，随后回查
  8. 解除关联DELETE/app/device/bind/{id}DELETE 路径传绑定记录 ID

扫描、GATT 连接和身份读取是本地 BLE 操作，不是 HTTP 绑定。BLE 广播名称或 MAC 尾号不能替代完整 IMEI。

绑定仍走 POST /app/device/bind，解绑按 bindingId 走 DELETE；不混用人员 / 宠物路径下的重复写入口。

2业务流程怎么走

  1. 连接读身份

    蓝牙入口仅接受支持的 EV04 / EV05 / EV07B 广播族；连接后读取固件版本、15 位 IMEI 和设备 MAC 回包，校验请求 SID、字段数量与长度。该步骤不保存参数。

  2. 核对设备与产品

    完整 IMEI 作为云端 deviceId，连接地址仅用于 BLE；已绑定设备入口必须与预期 deviceId 一致，再核对当前账号已有关系及可选产品。

  3. 选择使用者并绑定

    选择本人 ACTIVE 人员 / 宠物及产品。已有同一对象、产品关系时只确认；其他对象关系不自动改绑。提交一次 POST。

  4. 双视图确认

    对象 device-bindings 与 /app/device/bindings 的记录、设备、产品和目标均一致才确认成功；蓝牙接入随后按账号和环境保存已核验的本地关联。

  5. 解绑

    核对可信 bindingId 后 DELETE 一次，再查两个视图确认消失；解绑不等于删除设备、转移所有权或自动撤销所有授权。

3参数怎么区分

字段 / 区域来源 / 内容处理规则
deviceId设备标识 String当前校验为 1–128 位字母、数字、下划线或连字符；不要自行当作数值解析。
bindTypePERSON / PET与选择的使用者类型保持一致。
bindToId对象数字 ID（Long）来自人员 / 宠物资料，不传 PERSON:101 这样的组合值。
productKey可选产品返回值与选中的产品一致，不把产品名称或型号当作 key。
bindingId绑定记录的 id由查询结果取得，专用于核对和解绑，不等于 deviceId。
BLE 身份完整 IMEI、协议族、连接地址、固件版本连接地址可能随机变化；不能用名称尾号绑定，不向云绑定体夹带无关 BLE 字段。

4失败时怎么处理

  • 服务端拒绝

    保留可理解的拒绝提示，不继续进入成功页面。

  • 写入后超时 / 断网

    不能认定服务器没执行；进入结果未确认状态，先重新查询绑定关系，不自动重放写入。

  • 两个视图不一致

    记录重复、数量或内容不一致都不能确认成功，不从部分结果推断关系。

  • 账号或环境变化

    终止当前确认流程，丢弃旧上下文结果；不要把前一账号的关联写入当前列表。

  • 身份或本地关联失败

    IMEI 不匹配即断开，不继续绑定；绑定已确认但本地关联保存失败时单独报错，先回查关系，不盲目再绑。

5哪些内容还要补

  • 仍需真机验证

    扫码入口、新版拒绝提示、断网后写入回查及真实硬件持续上报。

  • 后端待确认

    改绑 / 转移所有权、共享关系失效等规则。不能从解绑成功自动推定这些操作已完成。

  • 既有实机范围

    10-20 指定 EV07BA 完成真实解绑、失权、BLE 身份读取及新绑定回查。10-23 同设备新旧配置入口均出现 BLE_GATT_UNAVAILABLE，连接稳定性仍待复验；不外推其他型号已通过。

公共约定：需登录的业务请求使用 Bearer Token，后台公共层携带 lang 与地区格式的 X-TimeZone；ID 保持无损，写入结果不明时先回查。OAuth、账号、AI 客服和图片客户端按各自规则处理。
