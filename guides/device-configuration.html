网络与蓝牙统一设备配置技术说明

网络与蓝牙共用原物模型菜单、表单和围栏地图；按型号、连接方式、当前授权及已验收字段决定可读可写范围。

完整型号配置需要可信产品标识；当前网络编辑器支持 ev07b。共享 CONFIG 与 GEOFENCE 分别校验，缺可信型号时仅提供基础低电量流程和独立围栏只读摘要，不借用所有者 BLE 身份。原型保存仍为内存演示。

1用哪些接口

  1. 核对设备产品GET/app/device/{deviceId}/product自有关系确认后选择支持的物模型包
  2. 读取设备完整参数组GET/app/device/{deviceId}/propertyGET query：property=powerLowAlert 等组名
  3. 保存允许修改的完整组POST/app/device/{deviceId}/propertyPOST JSON：组名包裹完整原始组，仅替换允许字段
  4. 共享设备按独立 scope 复核GET/app/subjects/shares/received参数组使用 CONFIG，geoAlert 使用 GEOFENCE；两者不互相放行
  5. 网络工程动作POST/app/device/{deviceId}/functionfindMe / reboot / shutdown 使用 POST function、query functionId 和空 JSON；readConfiguration 则串行读取属性组

BLE 复用原 GATT / 协议映射和风险确认；没有独立的“蓝牙 HTTP 保存接口”。

Prod 使用正式 App property runtime，不启用历史 /c/v1 占位云网关。页面按账号、环境、设备和所选连接方式隔离数据。

当前读取覆盖113个已接入字段，不是完整出厂备份。参数组需要 CONFIG，geoAlert 需要 GEOFENCE；工程命令另核对 COMMAND、型号能力和动作专用确认，不能由 CONFIG 推定放行。

2业务流程怎么走

  1. 选择方式并读取

    确认自有关系，或共享设备具备对应 CONFIG / GEOFENCE 授权，并确认可信型号与当前可用连接方式。完整配置共用同一菜单、表单与地图；共享设备缺型号时仅进入基础配置或围栏只读摘要。读取不到的值保持未读取，不填默认值。

  2. 修改并保存

    仅修改当前能力开放的字段。网络保存前串行重读所涉完整组并检查冲突，普通位字段只改目标位；集合按原 index 提交变化槽位，未知成员保留。多组写入记录已完成组，后续失败保持部分成功 / 待确认，不重放整次保存。蓝牙沿用原整组校验和风险确认。

  3. 重新读取确认结果

    保存后另发一次读取，核对修改值和其余参数是否符合预期。提交接口的回显、设备 ACK 与实际参数回读分别确认；超时或核对不一致时先重新读取，不自动重复保存。

  4. 切换网络或蓝牙

    有未保存修改时，先让用户选择继续编辑，或放弃修改并切换。确认切换后取消旧读取，清空旧值、未保存修改及原风险确认，再通过新方式读取；旧方式晚到的结果不覆盖新值。

  5. 工程动作

    读取配置是多组只读查询。查找、重启和关机各用动作专用确认及单次 token；关机还需确认可现场恢复，取消不发命令。受理、ACK、重连和现场效果分别记录，不自动重试。

这里的“修改前读取值”是开始编辑时从设备读到的参数，用于检查保存前是否发生变化。文末的 Android 提交号则标识本说明对应的代码版本。

4失败和迟到结果怎么处理

  • 切换后旧结果返回

    旧连接方式的读取、状态查询和缓存不能覆盖当前值；App 只接受仍属于当前连接方式和当前读取任务的结果。

  • 离线或不可读

    显示明确离线 / 不支持，不用旧连接方式的数值或默认值伪装新读值；未成功读取设备参数、保存中或不可读时禁用保存。

  • 数据变化或结果不明

    保存前重读发现参数变化就停止；取消、超时、返回数据缺失或保存后核对不一致时要求重新读取，不自动重复保存。

  • 权限和业务拒绝

    Parameter error 按参数拒绝展示，不误报为用户无权限；身份或环境改变后拒绝旧操作。

  • 围栏清除与恢复

    圆形中心/半径、多边形顶点及清除均保留其他位置和参数；保存后独立 GET 回填派生 flag 和实际值，再编辑以新读值为准。离线/超时不能显示为未设置；不自动重发。

  • 写后失权或无法核对

    Repository 保持结果可能已应用的语义，不把失权当作确定未写入；不自动重发。当前账号无权查看时清除受限展示，待重新授权后再独立读取。

  • 多组部分成功

    已确认的组不撤回、不重复写；后续组失败或超时保持实际已应用的可能性和待确认状态，重新读取后再决定下一步。APN密码不进入页面读回或日志。
