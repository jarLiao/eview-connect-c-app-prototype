网络与蓝牙统一设备配置技术说明

网络和蓝牙共用同一套配置页面。先读取设备参数，再修改保存；切换连接方式后，重新读取设备数据。

当前复用原 EV07B 物模型的 28 项菜单，各项能否读写取决于所选连接方式。网络仅开放低电量阈值和短信前缀保存；其他字段只读或禁用。

1用哪些接口

  1. 核对设备产品GET/app/device/{deviceId}/product自有关系确认后选择支持的物模型包
  2. 读取设备完整参数组GET/app/device/{deviceId}/propertyGET query：property=powerLowAlert 等组名
  3. 保存允许修改的完整组POST/app/device/{deviceId}/propertyPOST JSON：组名包裹完整原始组，仅替换允许字段

BLE 复用原 GATT / 协议映射和风险确认；没有独立的“蓝牙 HTTP 保存接口”。

Prod 使用正式 App property runtime，不启用历史 /c/v1 占位云网关。页面按账号、环境、设备和所选连接方式隔离数据。

2业务流程怎么走

  1. 选择方式并读取

    确认是自己的设备且型号支持配置，打开同一配置页面，选择“网络”或“蓝牙”，读取设备当前参数。没有读到的值保持空白，不用默认值代替。

  2. 修改并保存

    只修改当前连接方式允许的字段。网络保存前再次读取整组参数，与开始编辑时读到的值比较；有变化就停止并提示重新编辑，没有变化才保留其他字段、发送一次保存请求。蓝牙继续执行原有整组校验和风险确认。

  3. 重新读取确认结果

    保存后另发一次读取，核对修改值和其余参数是否符合预期。提交接口的回显、设备 ACK 与实际参数回读分别确认；超时或核对不一致时先重新读取，不自动重复保存。

  4. 切换网络或蓝牙

    有未保存修改时，先让用户选择继续编辑，或放弃修改并切换。确认切换后取消旧读取，清空旧值、未保存修改及原风险确认，再通过新方式读取；旧方式晚到的结果不覆盖新值。

这里的“修改前读取值”是开始编辑时从设备读到的参数，用于检查保存前是否发生变化。文末的 Android 提交号则标识本说明对应的代码版本。

3哪些字段可以操作

字段 / 区域来源 / 内容处理规则
低电量powerLowAlert.power网络只修改阈值，不自动开启提醒；status 与未改字段保持，SDK 派生 flag 按阈值差量核对。
短信前缀smsOption.prefix网络只改 prefix；保留短信开关、密码及其他原始成员，不把联系人页整体视为可写。
定位上报timeInterval、workMode、heartBeat当前网络只读；上传组保存被 Parameter error 拒绝，页面与 Native 均阻止上传间隔编辑。
联系人和通话number、sosOption、phoneOption、smsOption网络读取已接入，联系人位置和空项保留；号码、SOS、通话及短信开关不开放保存。
其他物模型项原菜单属性、页面和 BLE 映射网络没有映射的字段原位禁用；蓝牙支持情况按产品 / 固件、连接和执行守卫判断。

4失败和迟到结果怎么处理

  • 切换后旧结果返回

    旧连接方式的读取、状态查询和缓存不能覆盖当前值；App 只接受仍属于当前连接方式和当前读取任务的结果。

  • 离线或不可读

    显示明确离线 / 不支持，不用旧连接方式的数值或默认值伪装新读值；未成功读取设备参数、保存中或不可读时禁用保存。

  • 数据变化或结果不明

    保存前重读发现参数变化就停止；取消、超时、返回数据缺失或保存后核对不一致时要求重新读取，不自动重复保存。

  • 权限和业务拒绝

    Parameter error 按参数拒绝展示，不误报为用户无权限；身份或环境改变后拒绝旧操作。
