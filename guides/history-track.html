历史轨迹技术说明

自有设备或已获 TRACK 授权的共享设备复用同一历史页；日历、轨迹、进度和记录列表共用查询与回放状态。

仅直接 DEVICE 分享；TRACK 独立于 LOCATION。原型继续使用合成轨迹与类型筛选演示，不请求服务器；正式 App 的定位类型映射与真实移动精度仍待确认。

1用哪些接口

  1. 按日取轨迹、按月取日期标记POST/app/device/{deviceId}/eventsquery：eventId=GeneralLocation；两种用途只改变时间范围
  2. 发现当前自有对象GET/app/subjects用于确认自有设备；不向共享接收者开放所有者档案
  3. 检查对象与设备绑定GET/app/subjects/person/{personId}/device-bindingsGET/app/subjects/pet/{petId}/device-bindings自有设备核对绑定；共享设备改按有效 TRACK 授权核对，不创建绑定
  4. 核对当前接收人的直接设备授权GET/app/subjects/shares/received非自有设备仅接受 ACCEPTED、未撤销且未到期的 DEVICE 分享；需要 TRACK
字段 / 区域来源 / 内容处理规则
请求体pageIndex=0、pageSize=100terms 使用 timestamp gte startMs / lt endExclusiveMs，value 为 JSON 数值毫秒；sorts 使用 name=timestamp、order=asc。
日期范围手机 IANA 时区日查询为当天零点至次日零点；月查询为月初零点至下月月初。沿用公共 X-TimeZone 与 lang。
响应records / total / pages / current / size检验 HTTP、code / ok、分页元数据及 ID；完整分页并复核身份和访问权限后才返回。每页继续复核上下文，后续分页再次核对授权；最多 100 页、60 秒有界查询。

顶层 startTime/endTime 会被忽略；旧 GET 在 10-23 实测 405，不能照旧快照调用。历史位置不拼 realtime 当前点，也不发送定位指令。

2记录怎么校验和绘图

字段 / 区域来源 / 内容处理规则
id稳定记录 ID保持无损；重复、变更、缺页等使整次查询失败，不展示半条轨迹。
timestamp / dateTime事件时间 / 设备定位时间分别解析有效的 12–13 位毫秒值；按定位时间排序，均须属于所查本地日期。
lat / lng原始坐标必须是有限 JSON 数值，拒绝越界、零坐标对和显式 locStatus=x。
coordinateSystem指定历史来源的兼容政策仅缺字段时默认 WGS84；显式 WGS84/GCJ02 优先，null 或未知不绘点。地图层只转换一次。

沿用 Smart Locator / Katchu 的来源政策：国内高德/Google 普通道路图使用 GCJ-02，境外原值；MapLibre 使用 WGS84。GPS 有效性仍为 UNKNOWN，兼容显示不冒充服务端正式确认；不从 data、statusCode 或当前实时状态猜定位类型。

3地图、播放和列表怎么联动

  • 共用状态

    记录 ID、当前索引和播放进度同属 ViewModel；点地图记录、点列表或拖进度后同步选中位置。

  • 回放节奏

    至少两条且均可绘点才播放。1× 按有效记录时间压缩至 20–60 秒，2×/4× 在此基础上加速；点间平滑移动，暂停保留位置，到末条停止，再播从头开始。

  • 地图视野

    首次或播放时展示路线全览；播放过程不逐点追镜头。静态记录点抽样减量，移动游标与已播放线单独更新；全览按钮可回位。

  • 断点与暂停

    原记录不相邻、超过 30 分钟、时间逆序、速度跳点超过 100m/s 或坐标系变化均断线。改日、筛选、打开日历、离页或后台暂停；插值不写回服务器。

4日历与失败状态怎么处理

  • 日期标记

    完整月记录按手机时区归组，可显示记录的日期下方标点；无记录的过去日期仍可选，未来日期不可选。

  • 缓存

    按当前设备/会话、月份和时区隔离，60 秒、最多 6 个月；刷新或改日清缓存。取消、切月或身份变化丢弃迟到结果。

  • 查询失败

    日期标记保持未知并允许手动选日；不能把未加载、网络失败、分页异常或超限当成无记录。日轨迹失败提供重试，空日清除旧图。

  • 单点与筛选

    单点可查看但不能播放；时段在当天完整记录中本地筛选，包含起止分钟。定位类型筛选等待正式字段映射。

  • 停留期间失权

    历史页前台每 15 秒复核会话与 TRACK 访问权；撤销、到期或移除 TRACK 后取消查询，清空记录、路线、选中、播放及日历缓存，关闭日历和筛选弹层。权限检查失败也清除旧数据，不能继续播放缓存轨迹。

当前没有新增日期统计端点；大月数据量建议后端提供按日聚合，不能以当前小样本查询代替容量验收。
