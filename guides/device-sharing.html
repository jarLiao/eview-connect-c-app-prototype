设备分享技术说明

直接 DEVICE 分享共用自有设备的五标签详情，按每项授权控制可见数据和可执行动作；分享角色不变成设备所有者。

只提供设备分享，不提供人员/宠物档案分享。当前接收人、已接受、未撤销、未到期的授权按设备合并；概览、地图、健康、告警、配置保留同一界面，解绑和使用者档案编辑仍仅属于所有者。

1用哪些接口

  1. 解析接收人账号GET/app/subjects/shares/granteeGET query：account；结果区分已注册与未注册
  2. 创建设备邀请POST/app/device/{deviceId}/sharesPOST 路径传 deviceId，body 传接收人、角色、权限和有效期
  3. 读取当前账号收到 / 发出的邀请GET/app/subjects/shares/receivedGET/app/subjects/shares/granted服务端一次返回列表，App 按 DEVICE、资源与当前参与者过滤
  4. 接受或拒绝邀请POST/app/subjects/shares/{shareId}/acceptPOST/app/subjects/shares/{shareId}/reject按 shareId 提交一次，再回查列表中的记录
  5. 修改、重发和撤销PATCH/app/device/{deviceId}/shares/{shareId}POST/app/device/{deviceId}/shares/{shareId}/resendDELETE/app/subjects/shares/{shareId}DEVICE 修改 / 重发走设备路径；撤销走通用 subjects/shares 路径
  6. 按授权查看共享设备GET/app/device/{deviceId}/stateGET/app/device/{deviceId}/realtimeLOCATION 读状态与位置；PROFILE-only 只读可访问状态，不请求本环境拒绝的 realtime
  7. TRACK 授权的日/月历史查询POST/app/device/{deviceId}/events不要求同时具备 LOCATION
  8. 健康、告警与综合读取GET/app/evaigc/devices/{deviceId}/healthGET/app/evaigc/devices/{deviceId}/alertsGET/app/evaigc/devices/{deviceId}/overviewGET/app/evaigc/devices/{deviceId}/alerts/{alertId}/analysis分别校验 HEALTH / ALERT；综合概览需要两者，告警解释随 ALERT
  9. 配置和围栏GET/app/device/{deviceId}/propertyPOST/app/device/{deviceId}/propertyCONFIG 与 GEOFENCE 独立；完整型号编辑还需可信型号
  10. 按 COMMAND 授权请求设备动作POST/app/device/{deviceId}/function查找与立即定位；工程动作另受型号、渠道和 Native 确认约束，不代表已完成共享动作实测

路径出现 /app/subjects/shares 不表示允许分享人员档案；业务资源仍为 DEVICE。

不使用管理端 ShareGrant CRUD 拼装邀请流程；接受、拒绝、重发和撤销都使用正式 App 命令。

2业务流程怎么走

  1. 创建

    所有者进入设备分享管理，解析接收人。已注册传 granteeUserId，未注册传 inviteAccount；选择角色、scopes 和有效期，提交一次并回查发出记录。

  2. 接收处理

    消息页只展示 DEVICE 邀请，只有目标接收人可处理有效待处理记录；接受 / 拒绝后以重新读取的状态确认。

  3. 共享查看

    设备列表展示直接分享设备；接收人进入与自有设备共用的卡片、操作区、五标签和底部导航。按当前有效 scopes 显示授权数据和按钮，不创建自有绑定或开放所有者档案。

  4. 修改与结束

    修改、重发、撤销后独立回读。共享详情前台每 15 秒刷新授权，历史页独立复核 TRACK；撤销、到期、降权或切账号/环境时清空受限数据、停止旧任务与回放。不自动补发命令。

3参数和状态怎么区分

字段 / 区域来源 / 内容处理规则
资源与接收人deviceId / shareId；granteeUserId / inviteAccount资源与授权记录不可互换；已注册传用户 ID，未注册保留账号，不虚构接收人身份。
位置与基础信息LOCATION / PROFILELOCATION 允许当前位置和时间；PROFILE 允许状态和获准来源中的基础遥测白名单。当前 81 PROFILE-only 的 realtime 被拒，客户端只请求 state，不能将其误判为从未上报。
轨迹TRACK独立查询历史与日历，不依赖 LOCATION；失权清空历史、地图、播放和日历缓存。
健康与告警HEALTH / ALERT健康与告警分别请求；综合概览混合两项数据，当前需要两者。已授权但被服务端拒绝时如实提示，不要求接收者重新绑定。
配置与围栏CONFIG / GEOFENCE分别放行参数组和 geoAlert，不互相推导；缺可信型号不开放完整型号编辑器，也不借用所有者 BLE 关联。
设备命令COMMAND查找、立即定位以及工程动作路径核对 COMMAND；工程动作还需当前型号能力和专用确认。COMMAND 不自动取得 LOCATION、TRACK 或 CONFIG；超时不自动重发，共享真实命令仍待验。
设备分享SHARE开放分享入口并在实际命令前重核授权；再分享能管理哪些记录、上游撤销后的处理仍待业务确认，不直接公开所有接收人记录。
角色与其他范围MANAGER / PUSH / 未知 scopeMANAGER 按现有 App 规则展开全部已知设备 scopes，仍不能解绑或修改使用者档案；PUSH 和未知 scope 不推导额外读取或写入能力。
有效期与状态expiresAt / clearExpiresAt；PENDING / ACCEPTED / REJECTED / REVOKED / EXPIRED修改清除有效期显式传 clearExpiresAt；状态回读与当前时间共同决定授权是否有效。

4异常和失权怎么处理

  • 未确认命令

    连接失败、超时或回查状态不符时保持未确认，不自动重发邀请或接受 / 撤销命令。

  • 旧档案目标

    PERSON/PET 创建、修改、重发在本地拒绝；旧邀请不显示，旧共享档案导航只返回。

  • 权限消失

    每次共享读取前后确认有效授权；权限拒绝、撤销、到期或账号 / 环境变化后清除旧受限结果。

  • 展示缺字段

    缺接收人名称或设备名称时按既定回退展示，不使用本地演示人物补齐服务端数据。

  • 混合 realtime 响应

    只交付当前授权的基础遥测/位置白名单；移除 alarmCode、alarmTime、健康扩展和未知 expands。没有授权的数据不透传给页面。

  • 原始数据与动作分开

    读取前后检查当前会话、环境和有效分享；写入/命令前再检查对应权限。权限变化取消旧健康/告警任务，重新授权时当前健康标签可自动读取。
