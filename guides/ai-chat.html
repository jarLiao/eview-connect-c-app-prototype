智能助手技术说明

从「我的 → 智能助手」直接提问。聚合服务按问题处理普通对话、知识库检索和设备工具调用。历史轨迹保留「AI 轨迹问答（全天）」入口。

以 Android 1.0.311 与 11 月 19 日固定机记录为准。原型聊天弹层使用演示内容。设备概览、健康汇总和单条告警分析各有独立接口，见相应专题。

1用哪些接口

  1. 读取当前默认模型GET/aiModel/list进入聊天预取；发送时按缓存情况再读取
  2. 创建用户问题POST/chat/createPOST 返回 messageId 字符串，作为读取回答的 key
  3. 读取该问题的回答流GET/chat/msg/listquery：key=messageId；Accept: text/event-stream

请求使用当前环境、Bearer Token、TENANT-ID、lang 和 X-TimeZone。一次问答固定语言供模型查询、POST 和 SSE 使用。后续消息读取最新的界面语言，实际回答语言仍由服务端决定。

当前两个路由都选择 Chat 类型的模型，优先使用服务端 defaultModel，随后使用同类型首个模型。模型列表按环境、租户和用户缓存 10 分钟，读取失败可沿用旧缓存或内置兜底。成功列表缺少 Chat 模型时提示不可用。

2一条消息怎么完成

  1. 确定入口

    通用入口使用聚合数据集 -3。轨迹入口复核读取权限，带入设备、所选自然日和时区，使用专用 MCP 数据集 -8。可编辑草稿后再发送。

  2. 创建问题

    复用当前入口的会话，创建用户消息和回答占位。提交 /chat/create 后检查 HTTP 和业务响应，将 data 无损解析为 Long messageId，随后作为 SSE 的 key。

  3. 读取回答

    打开 SSE，将正文、推理、工具和引用分开更新到同一个回答。收到的正文片段和空白完整保留。

  4. 收尾

    收到完成信号且已有有效正文才标完成。失败保留已收部分。主动停止或离页取消本地流。

会话按环境、账号及入口上下文隔离。轨迹上下文包含设备、日期和时区。切换上下文时停止旧请求，迟到片段无法写入新回答。

3字段和事件怎么用

字段 / 区域来源 / 内容处理规则
会话与消息conversationId；POST 返回 data → messageId → GET keyconversationId 为每个会话生成，后续提问继续复用。服务端 messageId 用于拉取对应回答，本地气泡有自己的 ID。数值 ID 不经浮点数转换。
问题内容role=user、content、time、modelNamecontent 去首尾空白；time 按手机时区生成 yyyy-MM-dd HH:mm:ss；modelName 来自模型选择结果。
数据集与上下文datasetId、tenantId、extDetails、websearch、inner聚合问答使用 datasetId=-3，由服务端选择是否检索知识库或调用设备工具，App 不附专用 mcpId。轨迹问答使用 datasetId=-8，附配置的 mcpId。两者均带用户和租户，websearch=false、inner=false。
轨迹查询窗口原设备 ID、所选日期的 [当地 00:00, 次日 00:00)、时区轨迹范围写入用户看得见的 content 草稿，按所选时区的完整自然日计算。事件时间、定位时间、记录完整性和分页需要在回答里明确。
SSE 正文纯文本、message、delta；content、answerText 等增量逐字追加，已知累计快照提取新增部分。推理单独显示。流式预览收起当前行未完成的粗体开标记，结束后按完整正文渲染。
工具与来源toolInfo / toolInfoList；extLinks工具和来源分别去重。推理、工具默认折叠，手动展开后保留状态。设备列表工具显示可读名称，宽表显示横滑提示。
完成信号done / complete、[DONE]、finish / finished识别并剥离完成标记。只有完成信号和非空白正文同时具备才通过。无完成信号就断开，或只有推理、工具结果、空白正文，均标失败。
请求语言公共 lang 与消息 languageTag 快照发送时固定语言供 POST / SSE 使用，切语言不把已有流改成另一语言；界面语言和用户提问语言的策略分开判断。

当前请求体不发送 temperature、top_p、max_tokens 或 systemPrompt；不能把其他 AI SDK 的默认参数当成本接口字段。

4取消和重试怎么处理

  • 发送 / 流失败

    空 messageId、非法 ID、业务失败及 SSE 错误均标失败，保留已收正文并解除发送限制。HTTP 401 或明确提示凭证过期的 HTTP 424 给出重新登录入口。

  • 手动重试

    失败气泡可重试：在同一会话重新 POST 原问题，取得新 messageId；保留原用户气泡，替换失败的回答占位，不是从旧流断点继续。

  • 主动停止

    先发布 STOPPED 状态，再取消 SSE；无内容显示已停止，有内容保留已收部分。停止本地连接不证明服务器已停止生成。

  • 返回恢复

    同一账号 / 环境 / 入口可恢复进程内快照和输入；旧 STREAMING 改为 STOPPED，不自动恢复流。进程被杀后没有服务端历史恢复能力。

5真机验证与待核对项

  • 普通问答与知识库

    同一聚合入口下，12 + 30 返回 42。GPS 与 Wi-Fi 定位差异问答显示相关知识库引用。

  • 设备查询

    实际调用设备列表工具，答复返回 4 台，与测试 App 里的 2 台自有和 2 台共享一致。测试只读取数量。

  • 轨迹问答

    所选自然日的草稿与旧版逐字一致。专用路由实际调用轨迹查询工具，返回 10 条原始记录，与历史页 9 条有效和 1 条隐藏记录一致。首答最早定位时间比历史页晚 40 秒，追问后与历史页一致。首答准确性仍待核对。

  • 会话恢复与覆盖

    返回「我的」再进智能助手，恢复原聚合会话。Prod、Mock 构建与 168 项单测通过。登录过期分支有单测覆盖。跨进程服务端历史、断点续传、语言一致性和全部业务答案的正确性仍待独立验证。

公共约定：需登录的业务请求使用 Bearer Token，后台公共层携带 lang 与地区格式的 X-TimeZone；ID 保持无损，写入结果不明时先回查。OAuth、账号、AI 客服和图片客户端按各自规则处理。
